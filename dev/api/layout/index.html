Layout API Reference

This page documents the layout computation, timeline visualization, and filmstrip functions in NDTV.jl.

Animation

NDTV.render_animation — Function
render_animation(dnet::DynamicNetwork; algorithm=FRLayout(),
                 n_frames=100, interpolation=:linear, rng=...)

Compute layout positions for animating a dynamic network over its observation period. Works for any NetworkDynamic time type (including DateTime). Returns a DynamicLayout (interpolation = :linear or :none) or an InterpolatedLayout (interpolation = :ease).

NDTV.compute_animation_layout — Function

Compute layout positions for animating a dynamic network over its observation period. Works for any NetworkDynamic time type (including DateTime). Returns a DynamicLayout (interpolation = :linear or :none) or an InterpolatedLayout (interpolation = :ease).

Layout Computation

NDTV.compute_slice_layout — Function
compute_slice_layout(dnet::DynamicNetwork, time; algorithm=FRLayout(),
                     rng=...) -> Dict

Layout for the network snapshot at one time point, keyed by the dynamic network's stable vertex IDs (all vertices are retained; inactive ones are placed as isolates).

source
NDTV.layout_sequence — Function
layout_sequence(dnet::DynamicNetwork, times; algorithm=FRLayout(),
                anchor=true, rng=...) -> DynamicLayout

Layouts for a sequence of time points. With anchor=true (default) each frame is seeded from the previous frame's positions — matched by stable vertex ID — so vertices move smoothly. Per-frame active vertices and edges are recorded for rendering.

source
NDTV.compute_layout — Function
compute_layout(net::Network, algorithm; rng=Random.default_rng())
    -> Dict{T, Tuple{Float64, Float64}}

Compute a static layout keyed by the network's vertex IDs.

source
NDTV.get_position — Function
get_position(layout::InterpolatedLayout, vertex, time) -> Tuple{Float64, Float64}

Interpolated position of a (stable-ID) vertex at any time point. Works for any time type supporting subtraction with / (numbers, DateTime).

Filmstrip

NDTV.filmstrip — Function
filmstrip(dnet::DynamicNetwork, times; algorithm=FRLayout(), rng=...)

Layout frames at the given times for filmstrip (small-multiples) display. Each frame records positions (stable IDs), the active vertex set, active edges, and their counts.
